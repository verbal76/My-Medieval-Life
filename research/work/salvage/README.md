# Salvaged drafts from the stopped parallel run

The 12 parallel reading agents were stopped by the owner's instruction before any of them wrote a
batch file. These are the partial record drafts they left behind. They are **incomplete and not
validated**, and they count for nothing towards chapter coverage. Every chapter is re-read and
recorded in the single-session notes (`research/extraction/notes/`). These files may be consulted
only as a cross-check.
