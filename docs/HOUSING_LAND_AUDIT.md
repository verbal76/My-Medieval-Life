# Housing, land ownership and building placement: audit (2026-10-18)

The owner asked for this audit before any construction or property change (helpers delivering
materials, NPC house construction, land and workshop rentals). Findings only describe the code as
it is at commit `455e963`; recommendations are agent proposals awaiting the owner. Nothing was
changed in these systems.

## Findings

**What exists.** The only construction is the player building one house on one of two fixed plots.
NPCs never build, own land or move house. Nothing can be rented. There is no property tax.

- **Buildings.** 25, all generated by `tools/build_village.py`: 21 houses (9x10, door at x+4, y+9),
  the manor, the tavern, the sage's hut and the smithy. The only runtime building is the player's
  house (`player_house`, created by `World.deliver`, drawn from the single `stamps.house`).
- **Homes and households.** One household per home (tavern, manor, hut, houses); the household id
  is its index. NPC `home` and `household` are set at the start and never change. A dead household
  leaves an empty house nobody reoccupies. A house's crates and barrel are its household's pantry.
  The player's storage is `PlayerState.chest`; the home is the heir's respawn point.
- **Ownership is recorded six different ways:**

  | Thing | Field | Values |
  |---|---|---|
  | Plot | `owner` | `""` or the string `"player"` |
  | Field | `owner` | array of NPC ids |
  | Stall | `owner` | NPC id, -1 vacant |
  | Pen | `owner` | NPC id, -1 none |
  | Containers | derived | household (via home), tavern keeper, stall merchant |
  | Player | `home`, `plots` | building id, plot ids |

  Buildings and households have no owner field; "ownership" of a house is only the `home` link.
- **Land sales.** `World.buy_plot` sends the price to the treasury. `balance.json` `plot_price` is
  unused (the price is set in the generator).
- **Placement.** Only the two fixed plots (9x10) at (90,20) and (107,20); no grid or free placement.
- **Construction.** `start_site`, `deliver` (no owner check inside; the UI checks), `site_progress`,
  `cancel_site`; cost from `balance.json` `house_cost`. Delivered loads exist only as cost minus need.
  NPC repairs and public works use up materials bought by the treasury but build nothing.
- **Workshops.** 10 stations, none owned. NPCs reserve them; the player ignores reservations.
- **Employment.** Jobs set at the start; people move only between manor hand, farmer, woodcutter,
  hunter and miner. All wages come from the treasury. No villager employs anyone.
- **Saves.** Version 3. Buildings, households, plots, stalls, fields, pens and the player's home,
  chest and plots are saved; new map plots or buildings would not reach old saves.

## Defects found (not yet fixed: they touch ownership)

1. A farmer who changes jobs stays in the field's `owner` list (`npc_brain.gd::_change_job`), so
   taking that field's wheat can name a former farmer as the victim.
2. A stall that falls vacant is never let again (merchants are not in the job market).
3. The player can craft at a station an NPC has reserved.
4. `plot_price` in `balance.json` is unused.

## Conflicts to avoid

- A `"player"` string cannot name an NPC, a household or the manor.
- NPC-built houses need a household to live in; households are indexed by position and the
  container model derives ownership from `home`.
- Rent, deposits and helper pay must move only between counted purses (coin conservation test).
- Public works buy every plank above 6 per seller, which would starve builders.
- The player house's solid 9x9 block conflicts with walkable roof-fade interiors (being built).

## Recommendations (agent proposals, need the owner)

1. One owner reference for land, buildings and stations: `"manor"`, `"player"`, `"hh:<id>"`,
   `"npc:<id>"`. Unsold land belongs to the manor.
2. `owner` and `tenant` (with `rent`, `due_day`) on plots, buildings and stations; rent paid from
   the tenant's purse to the owner's (the treasury for the manor).
3. Generic construction: `start_site(plot, kind, owner)`, `deliver(plot, inv, by)` so helpers deliver
   while the owner keeps the building; costs per kind in `balance.json`; houses before workshops;
   NPC builders call the same functions.
4. Count site materials in the goods-conservation test; keep construction stock from public works.
5. Save version 4 with a migration (plot owners, new map plots and buildings).
6. Fix the four defects above.
