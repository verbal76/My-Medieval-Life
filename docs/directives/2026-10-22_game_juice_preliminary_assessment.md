# Owner directive, 2026-10-22: preliminary Game Juice pass (summary with the owner's words for the rules)

"Begin a preliminary Game Juice and Player Feedback assessment as a separate, unnumbered presentation workstream. This is
planning and evaluation only. Do not implement effects or change gameplay without approval." Objective: make existing
simulation activity "more visible, understandable, and satisfying without changing its underlying behavior."

Scope: player movement, interaction and action feedback; mining, forestry, farming, crafting, construction and tool
impacts; NPC animation, social reactions, visible activity; atmosphere, lighting, weather, particles, ambience; trading,
inventory, money transfers, notifications, UI feedback; combat, danger, injuries and consequences where mechanics exist;
sound and visual consistency; mobile readability, performance and accessibility.

Constraints: no change to simulation rules, outcomes, timing, economic values or determinism; "Presentation must reflect
actual events"; no effects implying nonexistent gameplay; keep the visual style and perspective; event-driven over
per-frame polling; no substantial GPU, CPU, memory or battery cost, especially on Android; no new mechanics; no duplicate
roadmap requirements.

Deliverable: an assessment document with an inventory of current feedback and reusable assets, opportunities by activity,
priority ranking (impact, effort, performance cost), quick wins vs larger upgrades, dependencies on Expansions 18-21,
required design decisions, a phased plan; confirmed observations kept apart from recommendations. Read-only: no gameplay
code, new assets, builds, simulations or merges; an idle worker only, without interrupting Expansions 18/19 or delaying
21; Build 17 frozen; recorded in the state and recovery handoff. Report the top ten improvements (benefit, complexity,
performance, order) and wait for approval.
